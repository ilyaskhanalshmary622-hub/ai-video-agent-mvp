# AI广告素材脚本与分镜助手

这是一个本地服务版 MVP，不再只是静态页面。

当前能力：

- 输入产品信息并生成结构化视频方案
- 上传产品图后，调用真实多模态模型提取产品信息并回填表单
- 调用真实大模型生成投手 / 制片级结果
- 支持竞品参考素材上传与对标拆解
- 自动导出 Markdown

## 启动方式

在当前目录运行：

```powershell
python server.py
```

启动后访问：

```text
http://127.0.0.1:8765
```

不要再用 `file://.../index.html` 方式打开，否则接口不会工作。

## 使用说明

1. 打开本地页面
2. 填入 `OpenAI API Key`
3. 上传产品图
4. 点 `识别产品图并回填`
5. 检查和补充表单
6. 点 `生成方案`

如果不填 API Key，前端会自动回退到本地规则模板。

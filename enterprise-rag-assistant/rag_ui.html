怎么补资料

管理员操作

把 Markdown 文件放进这个文件夹：

C:\Users\PC\Documents\视频创作\rag_practice_case\knowledge

推荐命名方式：

  • product__产品名.md：产品资料、卖点、禁忌。
  • ads__投放规则.md：Facebook、TikTok、AppLovin SOP。
  • customer__客服FAQ.md：售后、物流、质疑回复。
  • review__复盘案例.md：爆款、失败素材、数据结论。

保存后刷新网页即可读取。更稳可以重启服务。

DEPLOYMENT

部署说明

如果给别人试用，建议先加访问密码或只放脱敏资料。Key 放服务端环境变量，不放网页。

本地版

适合自己学习和演示。资料在电脑本地，模型调用 Agnes。

powershell -ExecutionPolicy Bypass -File .\start_rag_assistant.ps1

线上展示版

适合发链接给别人看。必须把 API Key 放到 Render 环境变量里。

AGNES_API_KEY / RAG_ALLOW_EXTERNAL / AGNES_MODEL

企业安全版

适合真实公司资料。需要登录权限、资料脱敏、操作日志和上传权限控制。

Auth + Audit Log + Private Knowledge Base

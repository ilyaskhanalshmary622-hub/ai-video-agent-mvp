# 官方资料机制与规则摘要
版本：2026-10-07；以下为来源短摘要，不能替代完整规则。

## S01 AppLovin：网站广告设置
核对日期：2026-10-07
官方摘要：网站电商与应用推广需区分；投放前连接像素并检查购买信号。广告目标、受众策略、转化窗口应匹配业务，不能照搬其他账户。
来源：https://applovin.com/en/resources/setting-up-campaign
适用：详见原文；不是对所有账户的保证。

## S02 AppLovin：网站广告优化
核对日期：2026-10-07
官方摘要：素材多样性、胜出创意的迭代和互动页均是优化方向。官方建议是起点，不是收益保证。
来源：https://applovin.com/en/resources/optimizing-campaigns
适用：详见原文；不是对所有账户的保证。

## S03 AppLovin：创意快速入门
核对日期：2026-10-07
官方摘要：创意包含视频与互动素材，需注意后续目录承接。文档建议早期抓注意、字幕和多种表现形式；时长与格式应以当前账户支持范围为准。
来源：https://applovin.com/en/resources/creative-quick-start
适用：详见原文；不是对所有账户的保证。

## S04 TikTok：事件去重
核对日期：2026-10-07
官方摘要：Pixel 与 Events API 上报同一事件时需要去重；相同事件使用一致 event_id。匹配用户与事件去重是两个问题。

适用：详见原文；不是对所有账户的保证。

适用：详见原文；不是对所有账户的保证。

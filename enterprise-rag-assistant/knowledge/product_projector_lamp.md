# 产品资料：海洋星空投影灯

产品名称：海洋星空投影灯

适用场景：
- 儿童卧室睡前氛围
- 情侣房间浪漫布置
- 家庭影院背景氛围
- 派对、生日、节日房间装饰
- 压力大的人群放松休息

核心卖点：
- 可投射海洋波纹和星空效果
- 多种颜色模式，可切换不同氛围
- 小体积，适合卧室、客厅、书房
- 操作简单，适合家庭用户
- 适合作为礼物送给孩子、情侣、朋友

目标人群：
- 年轻女性
- 有孩子的家庭
- 情侣和礼物购买人群
- 喜欢房间布置和氛围感内容的人群

广告注意事项：
- 不要承诺治疗失眠、焦虑或心理疾病
- 可以表达“放松氛围”“睡前仪式感”
- 画面要突出房间从普通变高级的反差
- 素材里最好有人物反应，不要只拍产品

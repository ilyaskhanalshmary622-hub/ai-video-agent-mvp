# 跨境运营知识包 2026-10-07

本次新增 20 个主题、100 个诊断问答；登记 30 个官方来源。

这是有范围的系统补充，不是全网全部知识，也不是任何人的真实操盘业绩。

## 使用方法

在问答中提供平台、市场、商品、统计周期、花费、净收入、购买数和主要异常。每条问题包括数据需求、排查动作、验收及来源。财税/法律部分只作运营核对入口，具体规则按地区和商品复核。

## 核验与维护

来源是官方页面正文或公开检索摘录，源文发布日期以原站为准。此处日期是采集核对日。摘要未覆盖全文细则。建议每月人工检查高频政策，重大变更即时修订；本次未创建自动更新任务。

## 特别处理

旧库的CTR 1%、频次3、ROAS 2、固定预算增幅等不再视为通用标准。素材仍遵循用户指定 image2 → seendans2.0。模型应优先引用带适用范围和日期的相关条目，避免泛化。

## 已知范围

已覆盖独立站经营、AppLovin、Meta基础排查、TikTok网站广告、Google和Amazon基础运营。未系统覆盖Shopee/Lazada/Temu全托管、各国实时税率、认证清单或企业自有账户数据；遇到这些问题需进一步核验，不应编造。
